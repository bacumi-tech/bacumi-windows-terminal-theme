# Contributing

Open an issue or pull request with the problem, proposed behavior and a small
non-sensitive example. Include your operating system, terminal, shell/framework
versions and Dark/Light choice. Please keep changes focused and run the checks
in the README.

Palette changes belong in `palette.json`; regenerate using `scripts/build.py`
and review both appearances. Keep the palette revision coordinated with the
other public Bacumi terminal-theme repository without adding a runtime or
build dependency on it. Generated theme definitions and illustrated previews
are committed deliverables; build archives remain ignored under `out/`.

Installation must preserve unrelated files, existing settings and local edits.
Contributions are provided under this repository's MIT license. Do not include
secrets, proprietary assets or third-party material without compatible rights.
