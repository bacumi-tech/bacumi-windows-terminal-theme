# Bacumi theme repository

- Keep installation and runtime standalone; no private sibling dependencies.
- MIT covers all shipped theme files, palette data, code, docs and illustrations.
- Never bundle private product code, brand kits, logos, fonts or credentials.
- Run the build consistency check, full tests and package check before a release.
- Preserve user configuration and local edits during install/update/uninstall.
- Keep previews labeled honestly and record native-platform validation limits.
- Do not publish a stable release before the native visual checklist is complete.
